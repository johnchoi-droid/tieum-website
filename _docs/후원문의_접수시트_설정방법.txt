 후원·문의 접수 시트 설정 방법 (약 5분 소요)
══════════════════════════════════════════════════

무엇이 달라지나요?
  지금은 방문자가 '문의하기'나 '후원 신청'을 하면 방문자 컴퓨터의
  메일 앱이 열리는 방식이라, 메일 앱이 없는 사람은 접수가 누락될
  수 있습니다. 아래 설정을 마치면 신청 내용이 구글 스프레드시트
  '티움 접수(문의·후원)'에 자동으로 쌓입니다.
  (설정 전에도 사이트는 기존 방식으로 정상 동작합니다)

※ 기존 '티움 멤버십' 스크립트는 그대로 두세요. 이것은 별개의
   새 프로젝트입니다.

──────────────────────────────────────
1단계. Apps Script 새 프로젝트 만들기
──────────────────────────────────────
  1. johnchoi@tieum.org 구글 계정으로 script.google.com 접속
  2. [새 프로젝트] 클릭
  3. 프로젝트 이름을 '티움 접수'로 변경
  4. 편집기에 기본으로 있는 코드를 모두 지우고,
     같은 폴더의 intake-apps-script.gs 파일 내용 전체를 붙여넣기
  5. 저장 (⌘S)

──────────────────────────────────────
2단계. 웹 앱으로 배포
──────────────────────────────────────
  1. 오른쪽 위 [배포] → [새 배포]
  2. 톱니바퀴(유형 선택) → [웹 앱]
  3. 설정:
       실행 계정: 나(johnchoi@tieum.org)
       액세스 권한: 모든 사용자     ← 중요!
  4. [배포] → 권한 승인(내 계정 선택 → 고급 → 이동 → 허용)
  5. 생성된 '웹 앱 URL'(https://script.google.com/macros/s/…/exec)을 복사

──────────────────────────────────────
3단계. 웹사이트에 URL 연결
──────────────────────────────────────
  1. index.html 파일을 열어 INTAKE_ENDPOINT 를 찾습니다 (⌘F)
  2. 다음 줄의 따옴표 안에 복사한 URL을 붙여넣기:
       window.INTAKE_ENDPOINT = '여기에 붙여넣기';
  3. 저장 후 git push (배포)

──────────────────────────────────────
4단계. 동작 확인
──────────────────────────────────────
  1. tieum.org 접속 → 문의 폼으로 테스트 메시지 전송
  2. 구글 드라이브에 자동 생성된 '티움 접수(문의·후원)'
     스프레드시트를 열어 '문의' 탭에 행이 추가됐는지 확인
  3. 후원 신청도 같은 방식으로 '후원신청' 탭에 쌓입니다

문제가 생기면:
  - 웹 앱 URL을 브라우저에 직접 열었을 때
    {"ok":true,"service":"TIEUM Intake","v":1} 이 보이면 서버는 정상
  - 코드를 수정한 경우: [배포] → [배포 관리] → 연필 아이콘 →
    버전: '새 버전' → [배포]  (이렇게 해야 URL이 유지됩니다)
